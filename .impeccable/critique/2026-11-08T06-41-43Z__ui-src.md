## Priority issues
- [P1] The Undo bar after deleting a chat is off-screen: DeleteFeedback renders after the 45-row list inside the scrolling panel (ChatTabContent.tsx:124, measured top 2986 px in a 900 px view). Fix: pin it to the bottom of the list panel; then the popconfirm can go. harden, layout.
- [P1] Tool names are code identifiers and differ by screen: dataBaseTool on the profile and form, databaseQuery in the trace; the agent list counts "1 tool" while the profile lists five. Fix: one human label per tool ("Database (read-only)"), function name in mono only inside the expanded call, a count that matches. clarify.
- [P2] Chat row menus lose focus: arrow keys do not enter the menu, Delete opens the popconfirm with focus on body, Esc drops focus to body (the chat rows do not use useMenuTrigger, unlike agent and KB rows). Fix: focus the first item on open, Cancel in the popconfirm, return to the trigger on close. harden.
- [P2] A refusal is styled as an error: REFUSED gets the same danger cross and red count as TOOL_ERROR (AgentRun.tsx:84-89, 368-369), so a guardrail working reads as a malfunction. Fix: a calm protective mark in ink for REFUSED, red only for real failures. colorize, clarify.
- [P3] Inert temperature/top P sliders at full weight (AgentFormModal.tsx:305-328); same document.title on every route; icon-only narrow top bar; touch targets under 44 px at 390. distill, polish, adapt.
